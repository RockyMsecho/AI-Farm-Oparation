                                Only Worker, Agronomist and Technician can be created here. Owner and Manager accounts are created through registration or by promoting an existing user's role below.

                                What each role can do

                                RoleZonesUsersReportsShift report
                                OwnerFull accessFull accessView + approve/rejectOwn + team
                                ManagerCreate / editAdd / manageView + approve/rejectOwn + team
                                AgronomistView only—View + recommendOwn only
                                Worker / TechnicianView only—Submit ownOwn only

                                Every row in this table is enforced by the backend, not just this page: Zones and Users were the first to get real permission checks, and Reports and the shift team-report followed the same pattern (reports.* and shifts.viewTeam in the RBAC permission table). A request outside these rules is rejected by the API itself, regardless of what this page shows.

                                Manage role permissions

                                Owner only

                                Choose a role and control exactly which backend permissions it receives. Changes are stored in the RolePermissions table and take effect for that role after users sign in again.

                                Help & Support

                                Quick guidance for using AI Farm and troubleshooting the connection.

                                Getting started

                                • Sign in with your farm account.
                                • Open Farm Structure to add Greenhouses and Growing Zones.
                                • Use Users & Roles to add staff and manage access.
                                • Use Reports and Operations modules to record farm activity.

                                If the server cannot be reached

                                • Make sure the ASP.NET Core backend is running on https://localhost:5226.
                                • Open https://localhost:5226/auth.html instead of opening the HTML file directly.
                                • If Chrome shows a certificate warning, run the included TRUST-HTTPS-CERTIFICATE.ps1 script once.
                                • If the API still fails, open https://localhost:5226/swagger to confirm the backend is running.

                                Access & permissions

                                • Owner and Manager can manage farm structure.
                                • Workers, Technicians and Agronomists can only perform actions allowed by their backend permissions.
                                • Changing what is visible in the dashboard does not replace backend authorization.
